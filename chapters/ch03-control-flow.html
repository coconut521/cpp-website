第3章 控制流

控制流让程序做选择（if / switch）和重复（while / do-while / for / range-for）。

学习目标

  • 用 if / else if / else 写多分支，说出悬空 else 的配对规则（就近，与缩进无关）；识别 if (a = 5) 这类把赋值当条件的写法。
  • 用 switch：case 必须是编译期常量、break 管住贯穿、default 兜底、字符串不能直接 switch。
  • 按场景在 while / do-while / for 之间选择，说清 do-while“至少执行一次”。
  • 写 range-for 遍历数组、vector、string，知道 auto& 何时该用。
  • 用 break / continue，记住 break 只跳一层。
  • 识别两类经典死循环（unsigned 回绕、循环变量不更新）并修复。

前置知识：第2章 运算符与表达式。

1. if / else 与悬空 else

if (条件) 里的条件按布尔值理解：非零为真，零为假。一个 if 只“拥有”紧跟的一条语句；想控制多条就必须用花括号包成语句块。悬空 else 的根源正在这里。

示例1：else 跟谁配对

知识点：悬空 else高频考点
#include <iostream>

int main() {
    int a = 5, b = 10;
    if (a > 3)
        if (b > 20)
            std::cout << "A\n";
        else
            std::cout << "B\n";
    return 0;
}
▶ 预期输出
B

逐行解释

  • 第5行：a > 3 为真，进入外层 if。
  • 第6行：b > 20 为假——注意外层 if 的“正文”就是这整个内层 if-else，还没完。
  • 第8~9行：走内层 else，打印 B。规则：else 总是与“尚未拥有 else 的、位置上最近的 if”配对，缩进只是给人类看的。

变体对比

把第 8 行的 else 故意缩进到与外层 if 对齐，语义一字不改——这就是“缩进欺骗”：

if (a > 3)
    if (b > 20)
        std::cout << "A\n";
else                      // 看着像属于外层 if，实际配的是内层！
    std::cout << "B\n";

想表达“外层的 else”，必须用花括号把内层 if 完整包住：if (a > 3) { if (b > 20) ... } else ...。

⚠ 易错点

判断题“else 与缩进对齐的 if 配对”——假。遇到误导性缩进，先在心里重排成真实结构再作答。

❌ 靠缩进判断配对

if (a > 3)
    if (b > 20)
        cout << "A";
    else
        cout << "B";
// 想要外层 else？赌输了

✅ 用花括号写明结构

if (a > 3) {
    if (b > 20) {
        cout << "A";
    }
} else {
    cout << "B";
}
// 结构即意图，谁也别猜

2. 把赋值当条件：if (a = 5)

示例2：少写一个 =，条件永远为真

知识点：= 与 ==高频考点
#include <iostream>

int main() {
    int a = 0;
    if (a = 5) {                          // ⚠ 想写 == 却写成了 =
        std::cout << "条件为真, a = " << a << "\n";
    }
    std::cout << "a 最终是 " << a << "\n";
    return 0;
}
▶ 预期输出
条件为真, a = 5
a 最终是 5

逐行解释

  • 第5行：a = 5 是赋值表达式，它的值就是被赋的 5（第 2 章）；5 非零 → 条件为真。于是 a 被悄悄改掉，判断也“永远通过”。
  • 第6行：进入分支时 a 已经是 5。
  • 第8行：a 最终是 5，而不是初始值 0——数据被污染了。

变体对比

两种防范写法：① 把常量写在左边，if (5 == a)——手滑写成 5 = a 会直接编译错误，错在编译期总好过错在运行期；② 开编译警告 -Wall，编译器会提示“suggest parentheses around assignment used as truth value”。若确实想“赋值并判断”，请显式加括号：if ((a = f()) != 0)。

⚠ 易错点

if (a = 0) 则相反：赋值表达式的值是 0，条件永远为假，分支成了死代码。

C++17 起给 if 也加了“带初始化”的形式：if (int x = f(); x > 0)——x 的作用域被收紧到整条 if/else 里，既防泄漏又防误用，与 switch 的同名新特性同期引入（见下一节）。

3. switch 与 case 贯穿

switch 按整数类型的表达式跳转到匹配的 case 标签。两个铁律：case 后面必须是编译期常量；不写 break 就一路执行到底（fallthrough，贯穿）。

示例3：case 空标签分组 + break + default

知识点：switch高频考点
#include <iostream>

int main() {
    int level = 2;
    switch (level) {
        case 1:
        case 2:
        case 3:
            std::cout << "基础组\n";
            break;
        case 4:
        case 5:
            std::cout << "进阶组\n";
            break;
        default:
            std::cout << "未知等级\n";
    }
    return 0;
}
▶ 预期输出
基础组

逐行解释

  • 第5行：level 为 2，直接跳到 case 2: 标签处。
  • 第6~7行：case 1:、case 2: 后面没有语句，顺序“落”到第 9 行——这是故意利用贯穿做分组：1、2、3 共享同一段代码。
  • 第9~10行：打印 基础组，break 跳出 switch。没有它就会继续打印“进阶组”。
  • 第15~16行：default 兜底：所有 case 都不匹配时执行（本例不会走到）。建议总是写上，哪怕只是提示“未知”。

变体对比：忘写 break 的贯穿

switch (level) {          // 设 level == 1
    case 1:
        std::cout << "一";   // 忘了 break！
    case 2:
        std::cout << "二";
        break;
}
// 实际输出：一二   ← 从 case 1 一路贯穿到 case 2

⚠ 易错点：case 要常量，switch 要整数

int n = 2;
switch (n) {
    case n:          // ⛔ 编译错误：case 后必须是编译期常量
        break;
}

std::string s = "hi";
switch (s) {         // ⛔ 编译错误：switch 条件必须是整数类型
    case "hi":       // ⛔ 字符串不能作 case 标签
        break;
}

要按字符串分流，用 if / else if 链（或后续章节的 map）。case 2 + 3: 合法——2+3 是常量表达式，等价于 case 5:。

C++17 起 switch 支持带初始化语句：switch (int n = f(); n)——临时变量的作用域被限制在这个 switch 内；同时新增 [[fallthrough]]; 属性，用来显式声明“这里的贯穿是故意的”，避免编译器警告。C++98/03 只能靠注释 /* fall through */。

4. 三种循环：while、do-while、for

三种循环能互相改写，差别在检查时机与写法分布：while 先判断后执行（可能一次不跑）；do-while 先执行后判断（至少跑一次）；for 把“初始化、条件、步进”三段收在一行，最适合次数已知的场合。

场景推荐理由
次数已知（循环 n 次）for三段式一眼看清“从哪到哪、步长多少”，不易漏更新
次数未知，先判断再干活while条件不成立时一次都不执行
至少要干一次（菜单、输入校验）do-while先执行后判断；注意结尾的分号不能少

示例4：同一个求和任务的三种写法

知识点：三种循环
#include <iostream>

int main() {
    // while：先判断，后执行
    int s = 0, i = 1;
    while (i <= 5) {
        s += i;
        ++i;
    }

    // do-while：先执行，后判断（至少跑一次）
    int t = 0, j = 1;
    do {
        t += j;
        ++j;
    } while (j <= 5);

    // for：初始化、条件、步进，三段写在一行
    int u = 0;
    for (int k = 1; k <= 5; ++k) {
        u += k;
    }

    std::cout << s << " " << t << " " << u << "\n";
    return 0;
}
▶ 预期输出
15 15 15

逐行解释

  • 第5~9行：i 从 1 累加到 5，s = 1+2+3+4+5 = 15；i 到 6 时条件 i <= 5 为假，循环结束。
  • 第12~16行：do-while 先做一轮再检查，结果同为 15。若初始 j 就是 6，do-while 仍会白跑一轮（t = 6），这正是“至少一次”的含义。
  • 第19~22行：for 的 k 只在循环内可见，写法最紧凑，结果同为 15。
  • 第24行：三种写法结果一致，输出 15 15 15。

变体对比

for 的三段都可以留空：for (;;) 是“无条件死循环”的惯用缩写（等价 while (true)），靠 break 退出。两个分号不能省。

⚠ 易错点

do-while 结尾的 while (条件) 后面必须带分号：} while (j <= 5);。漏掉分号是新手高频编译错误。

5. range-for：遍历容器元素

range-for（C++11 起）把“从头到尾逐个元素”写成一句话：for (声明 : 范围)。数组、std::vector、std::string 都能直接遍历——只写“要什么”，不用管下标从 0 到几。

示例5：遍历数组、vector、string

知识点：range-forC++11
#include <iostream>
#include <string>
#include <vector>

int main() {
    int arr[] = {10, 20, 30};
    for (int x : arr) {              // 遍历数组：每个元素来一遍
        std::cout << x << " ";
    }
    std::cout << "\n";

    std::vector<int> v = {1, 2, 3};  // 遍历 vector
    int total = 0;
    for (int x : v) {
        total += x;
    }
    std::cout << total << "\n";

    std::string s = "abc";           // 遍历 string：逐个字符
    for (char c : s) {
        std::cout << c << "-";
    }
    std::cout << "\n";
    return 0;
}
▶ 预期输出
10 20 30 
15
a-b-c-

逐行解释

  • 第7~10行：x 依次取 10、20、30，各输出一次加空格；第 10 行补换行。第一行末尾有一个空格。
  • 第14~17行：累加 1+2+3 = 15。range-for 里不用下标，也不用手写 ++i。
  • 第20~23行：string 的每个字符是 char，所以循环变量声明成 char c；输出 a-b-c-（每个字符后面跟一个减号）。

变体对比：x 是副本还是别名？

for (int x : v)        x *= 10;   // 改的是副本，v 原封不动
for (auto& x : v)      x *= 10;   // 引用：直接改原元素
for (const auto& s : words) ...  // 大对象只读：const 引用避免拷贝

int 这类小类型拷贝无所谓；但 std::string、std::vector 等大对象逐个拷贝很浪费——只读就写 const auto&，要改就写 auto&。

⚠ 遍历中修改容器：未定义行为

std::vector<int> v = {1, 2, 3};
for (int x : v) {
    v.push_back(x);   // ⛔ 遍历中让 vector 扩容
}
range-for 的底层依赖“指向元素的迭代器/指针”逐步推进；push_back 可能触发扩容（元素整体搬到新内存），使这些内部指针全部失效——之后继续遍历是未定义行为（崩溃、死循环、随机结果都有可能）。本课程规则：遍历容器时不增删元素；确需边遍历边改，用下标 + 手写 for 并理解代价。失效机制的完整原理留到 第 10 章展开。

6. break 与 continue

break 立即终止所在循环；continue 跳过本轮剩下的语句，直接进入下一轮（for 会先执行步进段）。两者都只对“自己所在的那一层”生效。

示例6：continue 跳过偶数，break 提前结束

知识点：break / continue高频考点
#include <iostream>

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; ++i) {
        if (i % 2 == 0) continue;   // 跳过偶数，回到 ++i
        if (i > 7) break;           // i = 9 时提前结束
        sum += i;
    }
    std::cout << sum << "\n";       // 1 + 3 + 5 + 7
    return 0;
}
▶ 预期输出
16

逐行解释

  • 第6行：i 为偶数时 continue，跳过第 7、8 行，直接回到 ++i——偶数不参与累加。
  • 第7行：奇数里一旦 i > 7（i = 9），break 终止整个循环，第 8 行不再执行。
  • 第8行：实际累加的是 1、3、5、7，sum = 16。

变体对比

把 break 换成 continue：i = 9 被跳过但循环继续，i = 10 也是偶数被跳过，最终同样输出 16——但循环“白跑到头”。两个语句要分清：break 终止整个循环，continue 只跳过这一轮。

多重循环：break 只跳一层。
for (int i = 0; i < 3; ++i) {       // 外层
    for (int j = 0; j < 3; ++j) {   // 内层
        if (j == 1) break;          // 只跳出内层
        std::cout << i << j << " ";
    }
    std::cout << "| ";
}
// 输出：00 | 10 | 20 |   ← 外层 3 轮照常跑完
想一次跳出所有层：① 用标志变量让每层都检查；② 把双层逻辑封装成函数用 return 退出；③ goto 能干这事，但极不推荐。

7. 死循环与循环变量陷阱

循环要能停，条件必须在某一轮变假。下面三个片段（非完整程序，请勿真跑）各自卡死在一个点上：

示例7：三个永远停不下来的片段

死循环示范（片段）
// 片段 1：unsigned 的 i >= 0 恒真 —— 回绕死循环
for (unsigned i = 3; i >= 0; --i) {
    std::cout << i << " ";
}

// 片段 2：写的是 i + 1，不是 ++i —— i 永远停在 0
for (int i = 0; i < 10; i + 1) {
    std::cout << i << " ";
}

// 片段 3：while 忘了更新循环变量
int n = 5;
while (n > 0) {
    std::cout << n << " ";   // 一直打印 5
}

逐段解释

  • 片段 1：输出 3 2 1 0 之后 i 减到 -1——unsigned 按 232 取模回绕成 4294967295，条件 i >= 0 对 unsigned 永远为真，于是 4294967295 4294967294 … 永远打下去。注意这不是 UB（无符号回绕是定义好的行为），而是“定义好的死循环”。修复：改用 int i，或条件写 i > 0。
  • 片段 2：i + 1 只是算出一个没人接收的临时值，没有副作用，i 永远是 0，条件恒真。修复：写成 ++i 或 i += 1。
  • 片段 3：循环体内忘了 --n;，条件永远成立。修复：体内更新循环变量。

⚠ 死循环不总是 bug

while (true) 配 break 是合法套路（游戏主循环、菜单程序），前提是循环体内确实存在出口。真正的危险是“以为有出口其实没有”——写完循环先问一句：什么情况下条件会变假？

8. 综合示例：嵌套循环与“未知次数”

示例8：嵌套循环打印下三角乘法表

综合高频考点
#include <iostream>

int main() {
    for (int i = 1; i <= 3; ++i) {       // 外层：行号
        for (int j = 1; j <= i; ++j) {   // 内层：列号不超过行号 → 下三角
            std::cout << j << "x" << i << "=" << j * i << " ";
        }
        std::cout << "\n";               // 每行结束换行
    }
    return 0;
}
▶ 预期输出
1x1=1 
1x2=2 2x2=4 
1x3=3 2x3=6 3x3=9

逐行解释

  • 第4行：外层 i 是行号，从 1 到 3。
  • 第5行：内层 j 从 1 跑到 i（注意条件是 j <= i）——第 i 行只打 i 项，形成下三角。
  • 第6行：每次打印形如 2x3=6 （后面跟一个空格）。
  • 第8行：内层跑完一行才换行——\n 在外层循环体里，不在内层里，位置差一行输出就全乱。

变体对比

想打完整九九表？把两处 3 都改成 9 即可，其余一字不动——这就是“外层管行、内层管列”结构的可扩展性。若把内层条件改成 j <= 3，会打出完整的 3×3 矩阵而不是三角。

⚠ 易错点

嵌套循环的总执行次数是内外轮数的乘积：本例 1+2+3 = 6 次（内层次数随 i 变化）。笔试题常问“第 6 行共执行几次”，按“外层每轮内层跑几圈”逐轮相加即可。

示例9：不知道循环几次？——本金翻倍问题

综合
#include <iostream>

int main() {
    double money = 100.0;      // 本金 100 元
    int year = 0;
    while (money < 1000.0) {   // 不知道要几年 → 未知次数用 while
        money = money * 2;
        ++year;
    }
    std::cout << "第 " << year << " 年达到 " << money << " 元\n";
    return 0;
}
▶ 预期输出
第 4 年达到 1600 元

逐行解释

  • 第6行：只要还没到 1000 就继续翻倍。“几年”无法事先算出（写在题面上的话另说），这正是 while 的主场。
  • 第7~8行：每年翻一倍、计数 +1。循环变量 year 在体内有更新，保证条件终会变假。
  • 第10行：100 → 200 → 400 → 800 → 1600，共翻 4 轮；1600.0 按 6 位有效数字显示为 1600。

变体对比

若把条件改成 money <= 800.0，800 也算达标：100 → 200 → 400 → 800，第 3 年结束，输出 第 3 年达到 800 元。边界用 < 还是 <=，答案差一年。

10. 常见错误

1. 把 == 误写成 =：if (a = 5) 恒真且污染 a。修复：常量放左边 5 == a，并开 -Wall。
2. 悬空 else / 多行正文不加花括号：else 就近配对，缩进不作数。修复：只要分支超过一条语句就加 {}；拿不准时一律加。
3. switch 忘 break / case 用变量或字符串：忘 break 会贯穿到下一 case；case n:（运行期变量）和 switch (字符串) 直接编译错误。case 只收编译期整数常量。
4. 两类死循环：for (unsigned i = 3; i >= 0; --i) 条件恒真（回绕）；for (int i = 0; i < 10; i + 1) 步进无副作用。修复：有符号计数 + 确保 ++i 真正发生。
5. 以为 break 能跳出所有层：嵌套循环里 break 只终结本层。要全跳：标志变量、封装成函数 return（goto 不推荐）。
6. range-for 遍历中修改容器：在 for (int x : v) 里 push_back / erase 会使内部迭代器失效，是未定义行为，没有“正确输出”可言。遍历时不增删元素，原理详见第 10 章。

特性C++98C++11C++17

判断题“range-for 在 C++98 里也能用”——假，它是 C++11 的新语法；考试若未注明标准版本，按现行标准（C++11 及以后）作答。

本章小结

控制流只做两件事：选择与重复。选择的核心是“条件的布尔值”（小心把 == 写成 =，else 就近配对）；重复的核心是“终止条件会不会变假”（小心 unsigned 回绕与不更新的循环变量）。
  • else 与最近的、尚未配对的 if 结合，与缩进无关；用花括号消除歧义。
  • if (a = 5) 先赋值再拿 5 当条件，恒真；if (a = 0) 恒假。
  • switch：case 必须编译期整数常量，忘 break 会贯穿（有时是特性），default 兜底，字符串不能用 switch；C++17 支持带初始化与 [[fallthrough]]。
  • while 先判后做，do-while 至少一次（结尾有分号），for 三段式适合已知次数。
  • range-for（C++11）遍历数组/vector/string；大对象用 const auto& 避免拷贝、auto& 就地修改；遍历中增删 vector 是 UB。
  • break 跳出本层循环、continue 跳过本轮；break 只跳一层。
  • 死循环三源：unsigned i >= 0 恒真、步进写成 i + 1、体内忘更新变量。
