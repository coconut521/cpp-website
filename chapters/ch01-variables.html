第1章 变量与基本类型

变量就是“给一块内存起个名字，并约定里面装什么类型的数据”。

学习目标

  • 说出变量的四个要素：类型、名字、值、地址。
  • 区分 int a;、int a = 1;、int a(1);、int a{1};、int a{}; 五种写法，说清 int a; 为什么不能直接读。
  • 用 sizeof 查看类型大小，知道结果因平台而异。
  • 用 auto、const、constexpr，说清后两者的区别。
  • 识别常见字面量（十/八/十六进制、浮点、字符、转义）。
  • 解释隐式类型转换的方向，避免窄化转换带来的精度丢失。

前置知识：无。

1. 变量：给内存起个名字

一条语句 int a = 42; 做了三件事：分配 4 字节内存、把这 4 字节命名为 a、把整数 42 以 int 的编码方式写入。此后读写 a 就是读写这块内存。

示例1：定义变量并输出

知识点：变量定义入门必会
#include <iostream>

int main() {
    int age = 20;          // 定义整型变量 age
    double score = 91.5;   // 双精度浮点
    char grade = 'A';      // 单个字符，用单引号
    bool pass = true;      // 布尔值：true / false

    std::cout << age << " " << score << " " << grade << " " << pass << "\n";
    return 0;
}
▶ 预期输出
20 91.5 A 1

逐行解释

  • 第4~7行：每行定义一个变量并初始化。注意字符用单引号 'A'，字符串才用双引号。
  • 第9行：<< 是“插入运算符”，把数据依次送入标准输出；" " 输出一个空格，"\n" 换行。
  • 第9行末尾：pass 是 true，但默认输出成 1。想让 bool 打印成 true/false，要用 std::boolalpha（见示例 10）。

变体对比

一条语句也可以定义多个同类型变量：int x = 1, y = 2, z;。但为了可读性，建议一行一个；未赋值的 z 在使用前必须先赋值。

⚠ 易错点

char grade = "A"; 是编译错误：双引号是字符串（类型 const char*），不能赋给 char。

2. 五种初始化写法

C++ 有多种初始化形式，结局并不相同：

示例2：int a; 与 int a = 1; / int a(1); / int a{1}; / int a{};

知识点：初始化形式高频考点
#include <iostream>

int main() {
    int a = 1;   // 拷贝初始化
    int b(2);    // 直接初始化
    int c{3};    // 列表初始化（C++11 起）
    int d = {4}; // 列表初始化（等号可省）
    int e{};     // 值初始化：保证为 0

    std::cout << a << " " << b << " " << c << " " << d << " " << e << "\n";
    return 0;
}
▶ 预期输出
1 2 3 4 0

逐行解释

  • 第4行：拷贝初始化，最常见。
  • 第5行：直接初始化，语法来自构造函数调用习惯。
  • 第6~7行：列表初始化，禁止窄化转换（见示例 5）。
  • 第8行：int e{}; 是值初始化，标准保证 e 为 0——这是它和 int e; 的本质区别。

变体对比

int a; 这种“只声明不初始化”的写法叫默认初始化：函数内的局部变量将处于未初始化状态——读它之前不赋值是未定义行为（本章示例 11 详解）。

⚠ 易错点

int a{}; 是 0，int a; 是垃圾值。

❌ C++98 时代的写法

int a = 1;
int b(2);
// 无法阻止窄化：
int x = 3.9;   // x == 3
int y = 'A';   // y == 65

✅ 现代写法（C++11 起）

int a{1};
int b{2};
int x{3.9};   // 编译错误！
              // 阻止窄化
int y{'A'};   // 合法：
              // char→int 无损
列表初始化 int c{3}; 是 C++11 新增；C++98 里只有 = 和 () 两种写法。用 g++ -std=c++98 编译示例 2 会得到“extended initializer lists only available with -std=c++11”警告——GCC 把花括号初始化当扩展放行，加 -pedantic-errors 才会升级为编译错误。

3. 基本内置类型与 sizeof

C++ 内置类型的大小不由标准统一规定，只规定约束关系（如 sizeof(long long) ≥ sizeof(long) ≥ sizeof(int)）。实际大小由编译器和平台决定。

示例3：用 sizeof 查看类型大小（Windows x64 典型结果）

知识点：sizeof平台差异
#include <iostream>

int main() {
    std::cout << "char   : " << sizeof(char)     << " 字节\n";
    std::cout << "bool   : " << sizeof(bool)     << " 字节\n";
    std::cout << "int    : " << sizeof(int)      << " 字节\n";
    std::cout << "long   : " << sizeof(long)     << " 字节\n";
    std::cout << "long long: " << sizeof(long long) << " 字节\n";
    std::cout << "float  : " << sizeof(float)    << " 字节\n";
    std::cout << "double : " << sizeof(double)   << " 字节\n";
    return 0;
}
▶ 预期输出（Windows 64 位，g++/MSVC）
char   : 1 字节
bool   : 1 字节
int    : 4 字节
long   : 4 字节
long long: 8 字节
float  : 4 字节
double : 8 字节

逐行解释

  • sizeof 是编译期运算符，返回字节数（类型是 size_t）。
  • 本例结果取自 Windows x64 的 LLP64 布局（Linux/macOS 的 64 位则是 LP64）：注意 long 在 Windows 上是 4 字节。

变体对比

同一程序在 Linux/Mac 的 64 位 g++ 下，long 输出 8 字节；在 16 位单片机上 int 可能只有 2 字节。

⚠ 易错点

“int 是 4 字节”的严谨说法是“典型平台上是 4 字节；标准只要求它至少 16 位宽”。写可移植代码应使用固定宽度类型 int32_t、int64_t（头文件 <cstdint>）。

标准只保证：char 恒为 1 字节；int ≥ 16 位；long long ≥ 64 位（C++11 起纳入标准）。“int 永远是 4 字节”这类说法不严谨。

4. 溢出：无符号环绕，有符号是 UB

示例4：unsigned 的“回绕”是定义好的行为

知识点：无符号算术高频考点
#include <iostream>

int main() {
    unsigned int u = 0;
    u = u - 1;   // 无符号运算按 2^32 取模，结果回绕到最大值

    int maxInt = 2147483647;   // 32 位有符号 int 的最大值
    std::cout << u << "\n";
    std::cout << maxInt << "\n";
    return 0;
}
▶ 预期输出
4294967295
2147483647

逐行解释

  • 第5行：无符号整数运算结果对 232 取模：0 - 1 回绕成 2^32 - 1 = 4294967295。这是标准明确定义的行为，不是 UB。
  • 第7行：2147483647 = 2^31 - 1，是 32 位有符号 int 的最大值。

⚠ 有符号整数溢出是未定义行为！

把示例中第 5 行改成 int i = 2147483647; i = i + 1;：有符号整数的算术溢出在 C++ 标准中是未定义行为——程序可能输出 -2147483648、可能崩溃、也可能被编译器优化掉。任何考试题若给出“有符号溢出后的确定输出”，题目本身就是错的；实际开发中必须避免溢出。

经典连环坑：for (unsigned i = n - 1; i >= 0; --i) —— i 减到 0 后再减一回绕成最大值，死循环（unsigned 永远 ≥ 0，条件恒真）。

5. 窄化转换

示例5：int x = 3.9; 通过，int x{3.9}; 报错

知识点：窄化转换高频考点
#include <iostream>

int main() {
    int a = 3.9;    // 旧写法：允许，静默截断
    int b{3.9};     // ← 编译错误！列表初始化禁止窄化
    std::cout << a << "\n";
    return 0;
}

/* g++ 报错（节选）：
   error: narrowing conversion of '3.8999999999999999e+0'
          from 'double' to 'int' [-Wnarrowing]
   简言之：3.9 → int 会丢失小数部分，{} 拒绝放行 */
▶ 预期输出（若把第 5 行注释掉）
3

逐行解释

  • 第4行：拷贝初始化允许隐式窄化：3.9 直接砍成 3（向零截断），编译器最多给个警告。
  • 第5行：列表初始化规定：凡是“可能丢信息”的转换（double→int、int→char、int→bool 等）一律编译错误。

变体对比

int b{3}; 合法；char c{300}; 报错（300 超出 char 范围）；char c = 300; 编译通过但值由实现定义，通常是 44（300 对 256 取模）。

⚠ 易错点

“int x{3.9} 的值是多少？”——它根本没有值，编译都过不了。

6. auto：让编译器替你写类型

示例6：auto 按初始值推导类型

知识点：autoC++11
#include <iostream>
#include <string>

int main() {
    auto x = 5;                 // int
    auto y = 5.0;               // double
    auto z = 'c';               // char
    auto s = std::string("hi"); // std::string
    auto b = true;              // bool

    std::cout << x << " " << y << " " << z << " " << s << " " << b << "\n";
    return 0;
}
▶ 预期输出
5 5 c hi 1

逐行解释

  • auto 不是“动态类型”：类型在编译期就定了，之后不能再赋别的类型（x = 1.5; 会把 x 存成 1）。
  • 整数字面量默认 int，小数字面量默认 double，所以 x 是 int、y 是 double。

变体对比

auto y = 5.0f; 推导为 float；auto z = 5u; 推导为 unsigned int。字面量后缀（f、u、L）直接决定推导结果。

⚠ 易错点

auto a; 是编译错误：没有初始值就无法推导。判断题“auto 变量可以不初始化”为假。

7. const 与 constexpr

示例7：const 必须初始化；constexpr 是编译期常量

知识点：const / constexpr高频考点
#include <iostream>

int main() {
    const double pi = 3.14159;  // const：定义后不可修改
    // pi = 3;                  // ← 编译错误：assignment of read-only variable
    // const int bad;           // ← 编译错误：const 变量必须初始化

    constexpr int N = 5;        // constexpr：编译期就能算出的常量
    int arr[N];                 // OK：数组大小需要编译期常量

    std::cout << pi << "\n";
    std::cout << sizeof(arr) / sizeof(arr[0]) << "\n";
    return 0;
}
▶ 预期输出
3.14159
5

逐行解释

  • 第4行：const 变量一旦初始化，再赋值就是编译错误；因此 const 变量必须在定义时初始化。
  • 第8行：constexpr 强调“编译期已知”，可以当数组长度、模板实参。
  • 第12行：sizeof(arr)/sizeof(arr[0]) 是求数组元素个数的经典写法，得 5。

变体对比

int n; std::cin >> n; int a2[n]; 是“变长数组”，标准 C++ 不允许（GCC 作为扩展放行）——可移植写法用 std::vector<int> a2(n);（第 10 章详述）。

⚠ 易错点

const int M = f();（f 是运行期函数）是合法的 const，但不是 constexpr，不能做数组长度。判断题“const 变量一定能当数组长度”为假。

const = “我保证不改”；constexpr = “编译期就算出来，还保证不改”。凡能用 constexpr 的地方都更推荐 constexpr。

8. 字面量与转义字符

示例8：进制前缀、类型后缀、转义字符

知识点：字面量
#include <iostream>

int main() {
    std::cout << 42 << " " << 052 << " " << 0x2A << "\n"; // 十进制/八进制/十六进制
    std::cout << 3.14f << " " << 1e3 << "\n";             // float 后缀 / 科学计数法
    std::cout << 'A' << " " << (int)'A' << "\n";          // 字符与其编码值
    std::cout << "换行符本质是\\n，制表符是\\t\n";
    std::cout << "引号：\"单引号' 双引号\"\n";
    return 0;
}
▶ 预期输出
42 42 42
3.14 1000
A 65
换行符本质是\n，制表符是\t
引号："单引号' 双引号"

逐行解释

  • 第4行：三个字面量值都相等——052 是八进制（8×5+2=42），0x2A 是十六进制（2×16+10=42）。
  • 第5行：3.14f 是 float；不带 f 的小数是 double；1e3 即 10³=1000。
  • 第6行：(int)'A' 是 C 风格强制转换，输出字符的 ASCII 编码 65。
  • 第7~8行：字符串里 \\n 输出字面上的反斜杠+n；\" 在双引号字符串里输出双引号本身。

⚠ 易错点

十进制字面量不能以 0 开头：int month = 09; 是编译错误（9 不是八进制数码）；int x = 010; 是 8 不是 10。

9. 隐式类型转换

示例9：赋值时发生的隐式转换（截断与提升）

知识点：类型转换高频考点
#include <iostream>

int main() {
    int i = 3.99;        // double → int：向零截断
    int j = -3.99;       // 向零截断，不是四舍五入！
    char c = 'A';
    int n = c;           // char → int：提升为编码值
    double d = 7 / 2;    // 先整数除法 7/2=3，再 int→double
    bool bb = 42;        // 非 0 → true

    std::cout << i << " " << j << " " << n << " " << d << " " << bb << "\n";
    return 0;
}
▶ 预期输出
3 -3 65 3 1

逐行解释

  • 第4~5行：double 转 int 是向零截断：3.99→3，-3.99→-3。“四舍五入”的说法是错的。
  • 第7行：char 参与算术时按其编码值（这里是 ASCII 65）。
  • 第8行：7 / 2 两侧都是 int，先做整数除法得 3，之后才转成 double 3.0。想要 3.5 必须写 7.0 / 2 或 7 / 2.0（第 2 章详述）。
  • 第9行：任何非零值转 bool 都是 true。

变体对比

显式转换写法：static_cast<int>(3.99)（推荐，意图清晰）或 C 风格 (int)3.99。两者结果相同，但 static_cast 更容易被搜索和审查。

⚠ 易错点

double avg = (a + b) / 2; 当 a、b 都是 int 时结果仍是整数除法。正确写法 double avg = (a + b) / 2.0;。

示例10：bool 的输出与 boolalpha

知识点：bool 与流控制
#include <iostream>

int main() {
    bool b1 = 42;    // 非 0 → true
    bool b2 = 0;     // 0 → false
    int  i = true;   // true → 1

    std::cout << b1 << b2 << i << "\n";            // 默认输出 1 和 0
    std::cout << std::boolalpha << b1 << " " << b2 << "\n"; // 变成 true/false
    return 0;
}
▶ 预期输出
101
true false

逐行解释

  • 第8行：默认情况下 true 打印为 1、false 打印为 0，三个连起来就是 101。
  • 第9行：std::boolalpha 是流操纵符，设置后 bool 以文字形式输出（对同一流持续有效）。

⚠ 易错点

bool b = -2; 的输出是 1 而不是 -2：bool 只有两个值，任何非零都归一化为 true。

10. 未初始化变量

示例11：读取未初始化的变量（UB 示范）

未定义行为示范
#include <iostream>

int main() {
    int x;          // 默认初始化：局部变量未初始化
    std::cout << x << "\n";   // ⛔ 读取未初始化变量
    return 0;
}

⚠ 为什么没有“预期输出”？

读取未初始化的局部变量是未定义行为：程序可能输出 0、输出随机垃圾值、或在开启优化的编译器下产生完全无法预测的结果。因此本例不给出预期输出，考试也不允许把它的结果当标准答案。g++ 开警告可捕获此类问题：g++ -Wall -Wuninitialized。

规避方法：① 定义即初始化 int x = 0;；② 用值初始化 int x{};；③ 打开编译警告 -Wall 并当错误处理 -Werror。

11. 综合示例

示例12：综合运用——计算圆面积

综合
#include <iostream>

int main() {
    const double pi = 3.14159;   // 常量：圆周率不该被改
    double r = 2.5;              // 半径
    double area = pi * r * r;    // 面积 = πr²

    std::cout << "半径 " << r << " 的圆面积 = " << area << "\n";
    return 0;
}
▶ 预期输出
半径 2.5 的圆面积 = 19.6349

逐行解释

  • 第4行：pi 用 const 保护，防止误改。
  • 第6行：pi * r * r 中三者都是 double，浮点乘法得到 19.6349375。
  • 第8行：cout 默认输出 6 位有效数字，所以显示 19.6349 而不是 19.6349375。想完整显示需 std::setprecision（详见速查表“输入输出格式控制”）。

变体对比

若把 pi 声明成 const float：精度从约 15 位降到约 7 位，面积的存储值会从 19.6349375 变成约 19.6349382——本例默认 6 位有效数字下显示仍是 19.6349，但数值已经悄悄失真。

12. 常见错误

1. 未初始化就读取：int x; cout << x; 是 UB。修复：定义即初始化，或用 {} 值初始化。
2. 八进制陷阱：int x = 010; 是 8。十进制不要以 0 开头。
3. 窄化丢失数据：int n = 3.99; 得 3。需要数值时用 static_cast 并确认舍入方向（向零截断）。
4. char 与 string 混用：'a' 是字符、"a" 是字符串，类型不同不可互换。
5. 有符号溢出：int 最大值 +1 没有标准答案，是 UB；unsigned 回绕到 0 才是定义好的。

更多同类错误见 编译错误博物馆（如“未声明标识符”“窄化转换警告”），以及 考试易错点 中的“整数溢出”专题。

13. C++ 标准差异小结

特性C++98C++11 及以后
列表初始化 int a{1};不可用可用，且禁止窄化
auto 类型推导是存储类别关键字（几乎不用）按初始值推导类型
constexpr不存在编译期常量（数组长度等）
long long非标准（编译器扩展）标准保证 ≥ 64 位
类型大小随平台变化的完整对照，见速查表专区《基本类型与格式化输出》。

本章小结

变量 = 类型 + 名字 + 值 + 地址；类型决定内存大小和解释方式。初始化宁多勿少：{} 最安全。
  • 五种初始化：int a;（危险）、= 1、(1)、{1}、{}（保证 0）。
  • sizeof 是编译期运算符；类型大小是平台相关的。
  • unsigned 运算回绕有定义；有符号溢出是 UB。
  • {} 初始化禁止窄化转换。
  • auto 必须初始化；const 必须初始化且不可改；constexpr 还要求编译期可算。
  • double→int 向零截断；非零→bool 为 true；7/2 先整数除法。
