第10章 模板与 STL

模板让编译器按类型生成代码：写一次 myMax，int、double、string 都能用。STL（标准模板库）就是用这套技术实现的标准库：容器 vector、map、set，加算法 sort / find / accumulate。

学习目标

  • 写函数模板 template<typename T>，判断实参推导何时成功、何时必须显式指定（如 myMax<double>(3, 4.0)）。
  • 理解模板在编译期实例化，模板定义必须放头文件（两阶段检查）。
  • 实现简单的类模板 Stack<T>，知道类模板可以有默认参数。
  • 使用 vector 的多种初始化、push_back/pop_back、size/empty、insert/erase，区分 [] 与 .at()。
  • 识别迭代器失效的场景，写出 it = v.erase(it) 的正确删除循环。
  • 分清 map 的 [] 两种含义（不存在的 key 会被自动插入）、find/count 的用法、按 key 升序遍历；对比 unordered_map 选型；使用 sort（升序 / greater<int>() 降序 / 自定义 lambda）、find、count、accumulate、max_element。

前置知识：第1章 变量与基本类型（auto、列表初始化、const）；第7章 类与对象、第9章 移动语义与智能指针。

1. 函数模板：写一次，对所有类型生效

不用模板时，“求较大值”要按类型抄很多份。函数模板把“类型”变成参数：编译器每次看到调用，就按实参类型“照模具生成”一份真正的函数——这个过程叫实例化（instantiation），发生在编译期。

示例1：函数模板 myMax 与实参推导

知识点：函数模板高频考点
#include <iostream>
#include <string>

// 函数模板：T 是类型参数，调用时由实参推导（或显式指定）
template <typename T>
T myMax(T a, T b) {
    return a > b ? a : b;
}

int main() {
    std::cout << myMax(3, 7) << "\n";      // T 推导为 int
    std::cout << myMax(1.5, 2.5) << "\n";  // T 推导为 double
    std::cout << myMax<double>(3, 4.0) << "\n";  // 类型推导冲突：显式指定 T=double
    std::cout << myMax(std::string("abc"), std::string("abd")) << "\n";
    return 0;
}
▶ 预期输出
7
2.5
4
abd

逐行解释

  • 第5~8行：模板定义。编译器先检查模板本身“长得对不对”（语法与具体 T 无关的部分），此时不生成任何代码。
  • 第11行：两个实参都是 int → 推导出 T=int，编译器实例化出 int myMax(int, int) 并调用。
  • 第13行：myMax(3, 4.0) 直接写是编译错误——一个实参推出 int、另一个推出 double，T 冲突。myMax<double> 显式指定 T=double，于是 3 被转成 3.0，返回 4.0，cout 默认输出 4。
  • 第14行：std::string 支持 >（按字典序），所以模板对它同样有效——这就是“泛型”。

变体对比

想让两个实参允许不同类型，就声明两个类型参数：template <typename T, typename U>（见示例 2）。考试判断题：“模板函数在运行时根据实参类型选择代码”——错，实例化发生在编译期。

⚠ 易错点

myMax(3, 4.0) 编译不过，不会自动把 3 转成 double——“推导冲突”和“隐式转换”是两回事；只有显式指定（或两实参同类型）才行。

示例2：多类型参数模板

知识点：多类型参数
#include <iostream>
#include <string>

// 多类型参数：T 和 U 可以各自推导
template <typename T, typename U>
void printPair(const T& a, const U& b) {
    std::cout << "(" << a << ", " << b << ")\n";
}

// 单类型参数：每个用到的 T 都会实例化出一份真函数
template <typename T>
T twice(T x) { return x + x; }

int main() {
    printPair(1, 3.14);            // T=int, U=double
    printPair("score", 97.5);      // T=const char*, U=double
    std::cout << twice(10) << "\n";   // 实例化 twice<int>
    std::cout << twice(1.5) << "\n";  // 实例化 twice<double>
    return 0;
}
▶ 预期输出
(1, 3.14)
(score, 97.5)
20
3

逐行解释

  • 第6行：参数写成 const T&——模板里更是惯例：避免拷贝大对象，还兼容 string 这类不便拷贝的类型。
  • 第15~16行：T、U 各自独立推导，所以 int 配 double、const char* 配 double 都能编译。
  • 第18行：twice(1.5) 是 twice<double>，返回 3.0；cout 默认 6 位有效数字，显示成 3——不是丢了类型，是显示格式如此。

变体对比

第 16 行若写成 printPair<int>(1, 3.14)：只显式给出第一个类型，U 仍由 3.14 推导——模板实参可以只指定前几个，其余靠推导。

⚠ 易错点

把模板定义写进 .cpp、在另一个 .cpp 里调用 → 链接错误 undefined reference。原因见下面的“两阶段”说明。

为什么模板定义要放头文件（两阶段一句话）：编译器第一阶段检查模板定义本身（与 T 无关的部分），第二阶段在每个实例化点代入 T 再检查并生成代码——因此每个使用点都必须能看到完整定义。模板和 inline 函数一样，通常直接写在头文件里；只把定义放 .cpp 会在链接期报 undefined reference。

2. 类模板：自己实现一个 Stack<T>

类模板把“元素类型”参数化：写一个 Stack<T>，就有 Stack<int>、Stack<std::string> 无数个类可用。注意成员函数定义也写在类里（或随类写在头文件中）。

示例3：类模板 Stack<T>（基于 vector 实现）

知识点：类模板高频考点
#include <iostream>
#include <vector>
#include <cstddef>    // std::size_t
#include <stdexcept>
#include <string>

template <typename T>
class Stack {
public:
    void push(const T& x) { data_.push_back(x); }
    void pop() {
        if (data_.empty())
            throw std::logic_error("pop from empty stack");
        data_.pop_back();
    }
    const T& top() const {
        if (data_.empty())
            throw std::logic_error("top of empty stack");
        return data_.back();
    }
    bool empty() const { return data_.empty(); }
    std::size_t size() const { return data_.size(); }
private:
    std::vector<T> data_;    // 复用 vector 存元素
};

int main() {
    Stack<int> s;               // 实例化 Stack<int>：成员 data_ 就是 vector<int>
    s.push(1);
    s.push(2);
    s.push(3);
    std::cout << s.top() << " " << s.size() << "\n";
    s.pop();
    std::cout << s.top() << " " << s.size() << "\n";

    Stack<std::string> names;   // 同一个模板的另一种实例化
    names.push("C++");
    std::cout << names.top() << "\n";
    return 0;
}
▶ 预期输出
3 3
2 2
C++

逐行解释

  • 第28行：Stack<int> 不是“一个类”，而是让编译器用 int 代入模板生成的一个类；Stack<std::string> 是另一个完全独立的类。
  • 第12、17行：栈空时 pop/top 无意义，抛异常报告错误（异常机制第 11 章详解）。
  • 第32~34行：后进先出——top 是 3、size 是 3；pop 后 top 变 2。

变体对比（模板默认参数一句话）

类模板也能有默认参数：template <typename T, typename Container = std::vector<T>> class Stack; —— 使用时省略第二个实参就默认用 vector<T>。标准库的 std::stack 正是这样设计的（底层容器还可以换成 deque/list）。

⚠ 易错点

模板类名不能“裸用”：类模板内部可以直接写 Stack，但类外代码必须写 Stack<int>——少了 <int> 就是编译错误。

3. vector：最常用的动态数组

std::vector<T> 是“可自动扩容的数组”：元素在堆上连续存放、支持下标随机访问、尾部增删都是 O(1)。

示例4：vector 的初始化、增删与 [] / .at() 的区别

知识点：vector 基础入门必会
#include <iostream>
#include <vector>
#include <stdexcept>

int main() {
    std::vector<int> v1;             // 空向量
    std::vector<int> v2(3);          // 3 个元素，值初始化为 0
    std::vector<int> v3(3, 9);       // 3 个元素，都是 9
    std::vector<int> v4 = {1, 2, 3}; // 列表初始化（C++11）

    v1.push_back(10);                // 尾部追加
    v1.push_back(20);
    v1.push_back(30);
    v1.pop_back();                   // 移除尾部元素 30

    std::cout << v1.size() << " " << std::boolalpha << v1.empty() << "\n";
    std::cout << v1[0] << " " << v1[1] << "\n";    // [] 不检查越界
    std::cout << v3[1] << " " << v4[2] << "\n";

    std::vector<int> w = {1, 2, 3};
    try {
        std::cout << w.at(1) << "\n";            // 合法下标
        std::cout << w.at(5) << "\n";            // 越界：抛 std::out_of_range
    } catch (const std::out_of_range&) {
        std::cout << "at 越界：捕获异常\n";      // what() 文字因编译器而异，不打印
    }
    return 0;
}
▶ 预期输出
2 false
10 20
9 3
2
at 越界：捕获异常

逐行解释

  • 第6~9行：四种初始化要分清——(3) 是 3 个 0；(3, 9) 是 3 个 9；{1, 2, 3} 是逐个列出（C++11 列表初始化）。
  • 第11~14行：push_back 尾部追加、pop_back 移除尾部（不返回被删元素）。v1 先变 [10,20,30] 再变 [10,20]。
  • 第16行：size() 返回元素个数（类型是无符号 size_t）；boolalpha 让 bool 显示成 true/false（第 1 章讲过）。
  • 第17~18行：[] 直接按下标取元素，不做任何检查。
  • 第22~25行：.at(i) 功能一样，但先检查下标：越界抛 std::out_of_range。异常机制第 11 章详解；at 更安全，[] 更快。

变体对比

把第 23 行换成 w[5]：编译照样通过、运行“可能”也看不出异常——但这是未定义行为（见本章“常见错误”第 2 条）。调试期想被立刻拦住，就用 .at()。

⚠ 易错点

std::vector<int> v(3); 与 std::vector<int> v{3}; 不同：前者是 3 个 0，后者是只有 1 个元素 3。圆括号看“数量”，花括号看“内容”。

示例5：遍历 vector 的三种写法

知识点：迭代器 / range-for
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {4, 5, 6};

    // 写法一：下标遍历（需要“随机访问”能力的容器）
    for (std::size_t i = 0; i < v.size(); ++i)
        std::cout << v[i] << " ";
    std::cout << "\n";

    // 写法二：迭代器遍历（所有 STL 容器通用）
    for (std::vector<int>::iterator it = v.begin(); it != v.end(); ++it)
        std::cout << *it << " ";
    std::cout << "\n";

    // 写法三：range-for（C++11，日常首选）
    for (int x : v)
        std::cout << x << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
4 5 6
4 5 6
4 5 6

逐行解释

  • 三行输出相同；每行末尾其实多一个空格（<< " " 的效果），显示上看不出来。
  • 写法一：size() 返回无符号 size_t，循环变量也用 std::size_t，避免“有符号/无符号比较”警告。
  • 写法二：迭代器是“泛化的指针”——begin() 指向首元素，end() 指向最后一个元素的下一位置（尾后，不指向任何元素）；*it 解引用取元素，++it 前进，用 it != end() 判断结束。第 12 行可用 auto it = v.begin() 简写。
  • 写法三：range-for 在编译期就展开成“迭代器循环”，等价于写法二，只是替你管好了迭代器。

变体对比

只想读不想改：range-for 写 for (const int& x : v)（或 const auto&），避免拷贝；vector 是连续存储，支持 v.begin() + 2 这种跳跃，list 则不支持。

⚠ 易错点

end() 不是最后一个元素，是尾后位置，对它解引用是未定义行为。循环条件必须写 it != v.end()，不要写 it <= v.end()。

示例6：insert / erase（在任意位置增删）

知识点：insert / erase
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30};

    v.insert(v.begin(), 5);        // 最前面插入 5 → {5, 10, 20, 30}
    v.insert(v.begin() + 2, 15);   // 插到下标 2 处  → {5, 10, 15, 20, 30}
    v.erase(v.begin() + 1);        // 删掉下标 1 的 10 → {5, 15, 20, 30}

    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
    std::cout << "size=" << v.size() << "\n";
    return 0;
}
▶ 预期输出
5 15 20 30
size=4

逐行解释

  • 第7~9行：insert / erase 的第一个参数都是位置（迭代器），不是下标；v.begin() + 2 表示“下标 2 的位置”（vector 连续存储才支持这种跳跃）。
  • 中间状态：插入 5 后是 {5,10,20,30}；在下标 2（元素 20）处插入 15 得 {5,10,15,20,30}；删下标 1（元素 10）得 {5,15,20,30}。
  • 第9行：erase 返回指向“被删元素的下一个”的迭代器——这个返回值怎么用，是示例 7 的主角。
  • size 与 capacity 一句话：size() 是当前元素个数；capacity() 是已分配空间能容纳的元素数，恒有 capacity ≥ size。超出 capacity 的 push_back 会触发“重新分配 + 整体搬移”；reserve(n) 可一次性预留。具体数值由实现决定，所以本例不打印 capacity。

变体对比

在 vector 中部 insert/erase 要搬移后面的所有元素，代价 O(n)；频繁在头部或中部增删应考虑 std::deque / std::list（本章不展开）。

⚠ 易错点

“size 是容量吗？”——不是。size 是装了多少，capacity 是能装多少；判断“是否为空”用 empty()，不要写 size() == 0 的老习惯（功能一样，empty 更清晰且对所有容器都高效）。

4. 迭代器失效（重点考题）

迭代器“指向”容器里的元素。但 vector 的元素住在一整块连续内存里——一旦这块内存被重新分配或元素被移动，原来保存的迭代器就成了“指向旧地址的野指针”。这叫迭代器失效。

示例7：边遍历边删除——erase 的正确姿势

知识点：迭代器失效高频考点易错
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 4, 5, 6, 8, 9};

    // 目标：删掉所有偶数
    for (auto it = v.begin(); it != v.end(); ) {
        if (*it % 2 == 0)
            it = v.erase(it);   // erase 返回“下一个”有效位置，必须接住
        else
            ++it;               // 保留的元素才手动前进
    }

    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
1 5 9

逐行解释

  • 第8行：循环的“前进”不再交给 for 的第三段，而是由循环体自己决定——删除时不前进（erase 的返回值已经指向下一个），保留时才 ++it。
  • 第10行：v.erase(it) 删除 it 指向的元素，并返回指向下一个元素的迭代器。it = v.erase(it) 就是标准写法。
  • 为什么必须接住返回值？因为 erase 会让“被删位置及其之后”的迭代器全部失效——原来的 it 已经不可用，能用的只有返回值。

变体对比

不手写循环也可以：v.erase(std::remove_if(v.begin(), v.end(), [](int x){ return x % 2 == 0; }), v.end());（erase-remove 惯用法）或 C++20 的 std::erase_if(v, ...)。但考试考的是手写循环版。

⚠ 易错点

最经典的错误是“for (...; ++it) 里调 v.erase(it)”——先失效再自增。下一小节的对比框给出正误写法。

❌ 错误写法：erase 后还 ++it

for (auto it = v.begin();
     it != v.end(); ++it) {
    if (*it % 2 == 0)
        v.erase(it);
    // erase 后 it 已失效，
    // 随后的 ++it 是未定义行为！
}

✅ 正确写法：接住返回值

for (auto it = v.begin();
     it != v.end(); ) {
    if (*it % 2 == 0)
        it = v.erase(it);
    else
        ++it;
}
失效迭代器不可用，也不可预测。auto it = v.begin(); v.push_back(4); std::cout << *it; —— 若 push_back 触发扩容，元素整体搬移到新内存，it 指向已被释放的旧内存，解引用它是未定义行为：可能输出垃圾、可能崩溃，也可能“碰巧正常”。规则：任何可能改变容量的操作（push_back、insert、resize…）之后，之前保存的迭代器、引用、指针一律视为失效，要用就重新取。

5. 关联容器：map、unordered_map 与 set

“关联容器”按 key 存取：map<K, V> 是键值对字典，set<K> 是“只有 key 的集合”。map 底层是红黑树（有序），unordered_map 底层是哈希表（无序）。

示例8：map 的 [] 两种含义（重点！）与升序遍历

知识点：map高频考点易错
#include <iostream>
#include <string>
#include <map>

int main() {
    std::map<std::string, int> score;
    score["alice"] = 90;    // key 不存在：先插入再赋值
    score["bob"] = 75;
    score["alice"] = 95;    // key 已存在：直接改值

    std::cout << score["alice"] << "\n";       // 查询（此时已存在）
    std::cout << score.count("bob") << "\n";   // 1：存在

    std::cout << score["carol"] << "\n";       // ⚠ 不存在：插入 {carol, 0} 并返回 0！
    std::cout << score.size() << "\n";         // 3：carol 被悄悄插进来了

    if (score.find("dave") == score.end())
        std::cout << "dave 不存在（find 不会插入）\n";

    for (const auto& kv : score)               // 按 key 升序（字典序）遍历
        std::cout << kv.first << "=" << kv.second << "\n";
    return 0;
}
▶ 预期输出
95
1
0
3
dave 不存在（find 不会插入）
alice=95
bob=75
carol=0

逐行解释

  • [] 的两种含义：key 已存在 → 返回对应值的引用（可读可改）；key 不存在 → 先插入 {key, 默认值}，再返回引用。int 的默认值是 0，std::string 的默认值是空串。
  • 第11~12行：此时 alice、bob 已存在，[] 表现为查询；count(k) 返回 0 或 1（map 的 key 不会重复）。
  • 第14~15行：只想查询却用 []，会把不存在的 key 连同默认值插进容器——size 变了、数据被污染。只查询请用 find / count / at()（at 对不存在的 key 抛 out_of_range，不插入）。
  • 第17行：find(k) 找不到时返回 end()，绝不插入；找到时返回指向该键值对的迭代器，用 it->first / it->second 取 key / value。
  • 第20~21行：map 遍历永远按 key 升序（底层红黑树有序）：字符串按字典序，alice → bob → carol。每个元素是 pair<const K, V>，用 kv.first / kv.second 访问。

变体对比

统计计数的最短写法正是利用“[] 会自动插入 0”：++freq[key];——第一次见到某 key 时先插入 0，再自增成 1。

⚠ 易错点

考试判断题：“m[k] 当 k 不存在时返回默认值，容器不变”——错，容器会插入新元素。反向也成立：打印 m.size() 前先想想有没有用 [] 查过不存在的 key。

示例9：unordered_map——哈希表、平均 O(1)、顺序不确定

知识点：unordered_mapC++11
#include <iostream>
#include <string>
#include <unordered_map>

int main() {
    std::unordered_map<std::string, int> age;
    age["tom"] = 18;
    age["jerry"] = 20;
    age["spike"] = 25;

    std::cout << age["jerry"] << "\n";      // 平均 O(1) 查找
    std::cout << age.count("tom") << "\n";  // 1

    // 遍历顺序由哈希决定、不确定——所以本例不遍历输出
    std::cout << "size=" << age.size() << "\n";
    return 0;
}
▶ 预期输出
20
1
size=3

逐行解释

  • unordered_map 用哈希函数把 key 映射到桶（bucket）里：查找平均 O(1)，最坏（哈希全撞车）退化为 O(n)。
  • 它的遍历顺序由哈希和桶的布局决定，既不是插入顺序也不是字母序，且不可预测——所以本例刻意不遍历输出。任何“给出 unordered_map 遍历输出”的考试题都是错题。
  • 需要的接口（[]、find、count、size）与 map 完全一致，可以随时互换。

变体对比（选型一句话）

要有序遍历或“找某个范围内的所有 key” → map；只要快、不在乎顺序 → unordered_map；拿不准先用 map——它的行为是确定的。

⚠ 易错点

unordered_map 的 [] 同样会“查无插入”，坑和 map 一模一样；另外它对 key 的要求是“可哈希 + 可判等”，自定义类型不像 map 那样只要提供 < 就够。

map 与 unordered_map 怎么选？

mapunordered_map
底层结构红黑树（平衡二叉搜索树）哈希表
遍历顺序按 key 升序不确定（不要依赖）
单次查找O(log n)平均 O(1)，最坏 O(n)
插入/删除后已有迭代器不失效（树结构稳定）rehash 时可能全部失效
对 key 的要求可用 < 比较可哈希、可用 == 判等
头文件<map><unordered_map>（C++11 起）

示例10：set——自动去重、自动排序

知识点：set
#include <iostream>
#include <set>

int main() {
    std::set<int> s;
    s.insert(30);
    s.insert(10);
    s.insert(20);
    s.insert(10);                 // 重复元素：被忽略，size 不变

    std::cout << s.size() << "\n";        // 3
    std::cout << s.count(20) << "\n";     // 1
    std::cout << s.count(99) << "\n";     // 0

    for (int x : s) std::cout << x << " ";  // 自动按升序排列
    std::cout << "\n";
    return 0;
}
▶ 预期输出
3
1
0
10 20 30

逐行解释

  • 第9行：set 里元素至多出现一次——重复 insert 是空操作，size 保持 3。
  • 第11行：插入顺序是 30、10、20、10，但 set 底层红黑树自动按升序摆放。
  • 第15行：遍历得到 10 20 30——有序，且无重复。set 没有 []（它不是“按位置”存取的），查找用 find/count。

变体对比

需要“去重但保留插入顺序”时，经典做法是 vector + set 辅助判重；需要“允许重复计数”用 multiset / multimap（count 可大于 1）。

⚠ 易错点

“set 会把后插入的大数排前面”——错，set<int> 默认升序。想让降序要写 std::set<int, std::greater<int>>。

6. 常用算法：sort / find / count / accumulate

算法住在 <algorithm>（数值类在 <numeric>），统一用迭代器区间 [begin, end) 指定“处理谁”——所以对 vector、数组、deque 都通用。

示例11：sort 三种用法 + find / count / max_element / accumulate

知识点：常用算法高频考点
#include <iostream>
#include <vector>
#include <algorithm>    // sort, find, count, max_element
#include <functional>   // std::greater
#include <numeric>      // accumulate

int main() {
    std::vector<int> v = {5, 2, 8, 2, 9, 1};

    std::sort(v.begin(), v.end());            // 默认：升序
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";

    std::sort(v.begin(), v.end(), std::greater<int>());  // 传比较器：降序
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";

    // 自定义比较 lambda：先按“除 3 的余数”升序，余数相同按数值升序
    std::sort(v.begin(), v.end(), [](int a, int b) {
        if (a % 3 != b % 3) return a % 3 < b % 3;
        return a < b;
    });
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";

    auto it = std::find(v.begin(), v.end(), 8);
    if (it != v.end())
        std::cout << "找到 8，下标 " << (it - v.begin()) << "\n";

    std::cout << std::count(v.begin(), v.end(), 2) << "\n";       // 2 出现几次
    std::cout << *std::max_element(v.begin(), v.end()) << "\n";   // 最大值
    std::cout << std::accumulate(v.begin(), v.end(), 0) << "\n";  // 求和，初值 0
    return 0;
}
▶ 预期输出
1 2 2 5 8 9
9 8 5 2 2 1
9 1 2 2 5 8
找到 8，下标 5
2
9
27

逐行解释

  • 第10~12行：sort 默认用 < 比较 → 升序：1 2 2 5 8 9。
  • 第14~16行：std::greater<int>() 表示“用 > 比较” → 降序。它来自 <functional>，末尾的 () 是“构造一个临时对象”。
  • 第19~24行：lambda（第 12 章详讲）自定义比较：余数 0 的排最前（9），余数 1 的次之（1），余数 2 的最后（2 2 5 8 按数值升序）。比较器必须“严格弱序”：相等元素要返回 false，所以余数相同要再比数值，绝不能写 <=。
  • 第26~28行：find 返回迭代器；找不到返回 end()，必须先判断再解引用。it - v.begin() 得到下标 5（第三个 sort 之后 8 在 v[5]）。
  • 第30~32行：count 数出现次数（得 2）；max_element 返回指向最大元素的迭代器，解引用得 9；accumulate 从初值 0 开始累加：9+1+2+2+5+8 = 27。

变体对比

accumulate 的第三个参数是累加初值，还决定累加类型：求 double 之和要写 std::accumulate(v.begin(), v.end(), 0.0)，写 0 就按整数累加截断。找最小值用 min_element，用法相同。

⚠ 易错点

比较器写 a <= b：对“相等的两个元素”返回 true，违反严格弱序——未定义行为（可能越界崩溃），见“常见错误”第 5 条。另外 sort 是不稳定排序，相等元素的先后不保证；需要稳定用 stable_sort。

示例12：综合运用——成绩统计

综合
#include <iostream>
#include <vector>
#include <map>
#include <algorithm>
#include <numeric>

int main() {
    std::vector<int> scores = {88, 92, 75, 88, 61, 92, 88};

    std::sort(scores.begin(), scores.end());   // 升序
    int total = std::accumulate(scores.begin(), scores.end(), 0);
    double avg = static_cast<double>(total) / scores.size();
    int hi = *std::max_element(scores.begin(), scores.end());

    std::cout << "总分=" << total << "\n";
    std::cout << "平均=" << avg << "\n";    // 默认 6 位有效数字
    std::cout << "最高=" << hi << "\n";

    std::map<int, int> freq;               // 分数 → 出现次数
    for (int s : scores) ++freq[s];
    for (const auto& kv : freq)            // 按 key（分数）升序输出
        std::cout << kv.first << "分:" << kv.second << "人 ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
总分=584
平均=83.4286
最高=92
61分:1人 75分:1人 88分:3人 92分:2人

逐行解释

  • 第11行：总分 584 = 61+75+88×3+92×2（排序后累加）。
  • 第12行：static_cast<double> 先转成 double 再除——直接写 total / scores.size() 是整数除法（第 1 章的坑）。584/7 = 83.428571…，cout 默认 6 位有效数字显示 83.4286。
  • 第19~20行：++freq[s] 借用 map 的“查无插入”：第一次见到某分数先插入 0，再自增——两行完成词频统计。
  • 第21~22行：map 按 key 升序遍历，输出 61 → 75 → 88 → 92；最后一行末尾有一个空格。

变体对比

要“从高到低”输出人数分布？把 map 换成 std::map<int, int, std::greater<int>>，遍历自动变成按 key 降序——不需要 sort。

⚠ 易错点

平均分写 total / scores.size()：整数 ÷ 无符号整数 = 整数除法，得 83——与第 1 章“7/2=3”同类错误。

8. 常见错误

1. 模板定义写进 .cpp：调用方只看到声明，实例化失败 → 链接错误 undefined reference to ...。修复：把模板（含类模板成员函数的定义）放头文件。
2. vector 下标越界用 []：v[v.size()]、v[100] —— operator[] 不做检查，越界读/写是未定义行为：可能输出垃圾值、踩坏别的数据、崩溃或“碰巧正常”。调试期用 .at()（越界抛 out_of_range），或访问前先判下标范围。
3. erase 后继续使用旧迭代器：v.erase(it); ++it; 或在 for (...; ++it) 中删除——自增/解引用失效迭代器是 UB。正确写法：it = v.erase(it);（示例 7）。
4. map 用 [] 查询不存在的 key：会静默插入默认值——size 变大、数据被污染。只查询用 find / count / at()。
5. sort 比较器写 <=：对相等元素返回 true，违反“严格弱序”，sort 内部行为未定义（可能越界崩溃）。比较器必须满足 comp(a, a) == false——用 <，别用 <=。
6. 依赖 unordered_map 的遍历顺序：顺序由哈希决定、不可预测。需要有序输出时换 map，或先把 key 拷进 vector 再 sort。

更多同类错误见 编译错误博物馆（如 “undefined reference”“no match for operator[]”），以及 考试易错点 中的“迭代器失效”专题。

9. C++ 标准差异小结

特性C++98C++11C++17
STL 容器与算法（vector/map/set/sort…）已有（STL 标准化的起点）扩充扩充
unordered_map / unordered_set无（仅编译器扩展）入标准—
vector<int> v = {1, 2, 3};（列表初始化）不可用新增—
range-for 遍历不可用新增—
lambda 自定义比较器不可用新增—
类模板实参推导（CTAD）——新增：std::pair p(1, 2.0); 可自动推导
模板本身从 C++98 起就是标准的一部分（STL 正是靠它实现的）；C++11 加入 unordered 容器、range-for 与 lambda；C++20 的 concepts 给模板参数加了“约束”，报错更友好——考试中看到“C++11 起才有 unordered_map”要能判断对错。

本章小结

模板 = 让编译器按类型“批量生成代码”的模具，实例化发生在编译期，定义要放头文件；STL = 容器 + 迭代器 + 算法。三条铁律：[] 不检查、at() 会抛异常；改容器后迭代器重新取；map 的 [] 查无插入。
  • 函数模板：实参推导失败（类型冲突）时显式指定 myMax<double>(3, 4.0)；多类型参数 <typename T, typename U>。
  • 类模板 Stack<T>；默认模板参数 typename Container = std::vector<T>。
  • vector：push_back/pop_back、size/empty、[] vs at()、insert/erase；size 是“装了多少”，capacity 是“能装多少”。
  • 迭代器失效：push_back 扩容全失效；删除必须 it = v.erase(it)；erase 返回下一个位置。
  • map：[] 两种含义（查无插入默认值！）、find/count 查询、按 key 升序遍历；unordered_map 哈希、平均 O(1)、顺序不确定；set 自动去重且有序。
  • 算法：sort（默认升序 / greater<int>() 降序 / lambda 自定义）、find、count、accumulate（注意初值类型）、max_element。
