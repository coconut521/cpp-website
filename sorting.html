排序算法专题

7 种常考排序一次讲透：冒泡、选择、插入、希尔、快速、归并、堆排序。前五种配逐步执行（行高亮 + 变量表 + 控制台），末尾附复杂度/稳定性对比总表、常考题型与随堂测验。

学习目标

  • 手写 冒泡 / 选择 / 插入 三种 O(n²) 排序，说出各自“每一轮结束后的确定结论”（冒泡沉底、选择就位、插入前缀有序）。
  • 理解稳定性与原地排序两个概念，能对每种算法判断二者。
  • 手写/读懂 快速排序（partition 划分）与 归并排序（合并有序段），说出分治思想与递归结构。
  • 记住对比总表：各算法的最好/平均/最坏复杂度、空间、稳定性，以及“什么时候选谁”。
  • 会做四类常考题：手算某轮后的数组状态、判断稳定性、快排一趟划分结果、比较次数量级估算。

前置知识：第3章 循环、第4章 函数与递归、第6章 数组。

1. 三个基本概念：复杂度、稳定性、原地

排序就是把一组数据按关键字升序/降序重新排列。评价一个排序算法，考试最常问三件事：

概念含义怎么考
时间复杂度比较/移动次数随数据量 n 增长的量级；分最好、平均、最坏三种情形“对 n=1000 的有序数组，冒泡要比较约多少次？”
稳定性关键字相等的两个元素，排完后仍保持原来的先后次序给 {3a, 3b, 1} 排序，问 3a 是否仍在 3b 前面
原地（空间 O(1)）只在原数组内交换/移动，不开与 n 同级的额外空间归并要 O(n) 临时数组——它不是原地的
稳定性为什么重要：实际数据常按多个字段排序——先按成绩排、再按姓名排（稳定），成绩相同的人仍保持姓名次序。稳定的排序：冒泡、插入、归并；不稳定的：选择、希尔、快排、堆排（记忆口诀见第 9 节）。

2. 冒泡排序（Bubble Sort）

思想：从头到尾两两比较相邻元素，逆序就交换——每一轮把当前最大的数“冒泡”沉到末尾。n 个数最多做 n−1 轮；第 i 轮结束后，最后 i 个元素必然就位，所以内层每轮可以少比一次。加一个 swapped 标志，某一轮没有任何交换就说明已经有序，可以提前结束（这正是“最好情况 O(n)”的来源）。

示例1：冒泡排序（提前退出优化）

知识点：冒泡高频考点
#include <iostream>

void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {         // 最多 n-1 轮
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; ++j) { // 已就位的尾部不用再比
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                swapped = true;
            }
        }
        if (!swapped) break;                  // 一轮没换 = 已经有序
    }
}

void printArray(int a[], int n) {
    for (int i = 0; i < n; ++i) std::cout << a[i] << " ";
    std::cout << "\n";
}

int main() {
    int a[5] = {5, 2, 4, 1, 3};
    bubbleSort(a, 5);
    printArray(a, 5);
    return 0;
}
▶ 预期输出
1 2 3 4 5

逐行解释

  • 第4行：外层轮数。n=5 时最多 4 轮；第 i 轮开始前，末尾 i 个元素已就位。
  • 第6行：内层边界 j < n - 1 - i——既保证 a[j+1] 不越界（-1），又跳过已就位的尾部（-i）。
  • 第8~10行：经典三行交换，必须借助临时变量 t。
  • 第14行：第 4 轮一次交换都没发生，说明剩余部分已有序，break 提前收工。对已经有序的输入，本实现只扫一遍就停 → 最好 O(n)。

特点与考点

  • 稳定：比较用严格大于 >，相等的元素不交换，先后次序保持。
  • 原地：只用了 t 一个临时变量，空间 O(1)。
  • 常考：问“第 2 轮结束后数组是什么样”——按轮手算即可，记住每轮末尾多一个就位元素。

3. 选择排序（Selection Sort）

思想：每一轮从“未排序区间”里选出最小值，与区间开头交换。第 i 轮结束后，前 i 个元素必然就位。与冒泡的区别：冒泡是“相邻比、随时换”，选择是“先记住下标、最后一轮只换一次”——交换次数最多 n−1 次，是所有 O(n²) 排序里交换最少的。

示例2：选择排序

知识点：选择高频考点
#include <iostream>

void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int minIdx = i;                        // 先假设开头就是最小
        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[minIdx]) minIdx = j;  // 只记下标，不急着换
        }
        if (minIdx != i) {                     // 找到更小的才交换
            int t = a[i];
            a[i] = a[minIdx];
            a[minIdx] = t;
        }
    }
}

int main() {
    int a[5] = {4, 1, 3, 5, 2};
    selectionSort(a, 5);
    for (int i = 0; i < 5; ++i) std::cout << a[i] << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
1 2 3 4 5

逐行解释

  • 第5行：minIdx 记的是“目前见到的最小值的下标”，不是值——交换时要用下标。
  • 第6~8行：扫描未排序区间 a[i+1..n-1]，只更新下标、不交换，这就是“选择”。
  • 第9~13行：整轮只做一次交换；minIdx == i 说明最小值本来就在开头，省去自交换。

特点与考点

  • 比较次数固定：无论输入是否有序，都是 1+2+…+(n−1) = n(n−1)/2 次——没有最好最坏之分，一律 O(n²)。
  • 不稳定（这是常考陷阱）：长距离交换会跨越相等元素。例：{3a, 3b, 1} 第 1 轮把 1 换到开头 → {1, 3b, 3a}，两个 3 的次序反了。
  • 想稳定又想“选最小”？把最小值插入到开头并整体后移（代价是移动多）——那就变成插入排序的思路了。

4. 插入排序（Insertion Sort）

思想：像整理手里的扑克牌——每次摸一张新牌（key），从右往左把比它大的牌依次右移，把它插进正确位置。始终保证前缀 a[0..i-1] 有序。数据基本有序时，内层 while 几乎不挪元素，接近 O(n)——这是它相对冒泡/选择的最大优势。

示例3：插入排序

知识点：插入高频考点
#include <iostream>

void insertionSort(int a[], int n) {
    for (int i = 1; i < n; ++i) {          // a[0..i-1] 已有序
        int key = a[i];                    // 新摸的牌
        int j = i - 1;
        while (j >= 0 && a[j] > key) {     // 比 key 大的往后挪
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = key;                    // 落座
    }
}

int main() {
    int a[5] = {3, 5, 1, 4, 2};
    insertionSort(a, 5);
    for (int i = 0; i < 5; ++i) std::cout << a[i] << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
1 2 3 4 5

逐行解释

  • 第5行：先把 a[i] 存进 key——右移会覆盖它原来的位置。
  • 第7~10行：条件是 j >= 0 && a[j] > key，两个条件顺序不能反（先判 a[j] 会越界）。挪动是覆盖赋值而不是交换，省一半写入。
  • 第11行：循环停下时 j 停在“第一个不大于 key 的位置”，key 落座在 j+1。

特点与考点

  • 稳定：右移条件是严格大于 >，相等的牌不越过。
  • 最好 O(n)：输入已有序时每轮只比较一次；最坏 O(n²)：逆序时每个 key 都要挪到最前。
  • 常考：插入排序对“基本有序”的数组效率最高；这也是希尔排序改进它的出发点。

5. 希尔排序（Shell Sort，选讲）

思想：插入排序的“分组加速版”。先按较大间隔 gap 把数组分成若干组，各组分别做插入排序；然后 gap 逐轮减半，最后 gap=1 时就是一次普通插入排序——但此时数组已基本有序，恰好踩中插入排序最快的情形。远距离的大幅挪动在早期轮次完成，后期只需微调。

示例4：希尔排序

知识点：希尔选讲
#include <iostream>

void shellSort(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {   // 间隔逐轮减半
        for (int i = gap; i < n; ++i) {          // 各组分别做插入
            int key = a[i];
            int j = i - gap;
            while (j >= 0 && a[j] > key) {
                a[j + gap] = a[j];
                j -= gap;
            }
            a[j + gap] = key;
        }
    }
}

int main() {
    int a[8] = {8, 3, 9, 1, 5, 7, 2, 6};
    shellSort(a, 8);
    for (int i = 0; i < 8; ++i) std::cout << a[i] << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
1 2 3 5 6 7 8 9

要点

  • 把插入排序里的“-1 / +1”换成“-gap / +gap”，就得到组内插入——对比示例 3 看非常清楚。
  • 本例 n=8：gap 依次取 4、2、1。gap=4 时数组分成 4 组（每组 2 个元素）先大致理顺。
  • 复杂度依赖增量序列：考试常写“平均约 O(n^1.3)，最坏 O(n²)（原始增量）”；不稳定、原地 O(1)。

6. 快速排序（Quick Sort）

思想（分治）：① 选一个基准（pivot，下例取区间末元素）；② 划分 partition：把小于基准的挪到左边、大于等于的留在右边，基准落到正中间——一轮 partition 后基准必然就位；③ 对左右两半递归同样处理。平均 O(n log n)，且常数小、原地（只需递归栈），是实践中最快的通用排序之一。

示例5：快速排序（Lomuto 划分）

知识点：快排 / 递归高频考点
#include <iostream>

int partition(int a[], int lo, int hi) {
    int pivot = a[hi];                 // 取末元素作基准
    int i = lo - 1;                    // [lo..i] 都是 < pivot 的
    for (int j = lo; j < hi; ++j) {
        if (a[j] < pivot) {            // 小元素换进左区
            ++i;
            int t = a[i]; a[i] = a[j]; a[j] = t;
        }
    }
    int t = a[i + 1]; a[i + 1] = a[hi]; a[hi] = t;  // 基准归位
    return i + 1;                      // 基准的最终下标
}

void quickSort(int a[], int lo, int hi) {
    if (lo >= hi) return;              // 0/1 个元素天然有序
    int p = partition(a, lo, hi);      // 分
    quickSort(a, lo, p - 1);           // 治：左半
    quickSort(a, p + 1, hi);           // 治：右半
}

int main() {
    int a[6] = {3, 6, 1, 5, 2, 4};
    quickSort(a, 0, 5);
    for (int i = 0; i < 6; ++i) std::cout << a[i] << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
1 2 3 4 5 6

逐行解释

  • 第4~5行：基准取 a[hi]；i 是“小于区”的右边界——a[lo..i] 全部 < pivot。
  • 第6~10行：扫描中遇到 < pivot 的元素，就把“小于区”扩大一格并把这个元素换进去。
  • 第12~13行：扫描结束后，a[i+1] 起都是 ≥ pivot 的元素——把基准换到 i+1，它左边的全小于它、右边的全不小于它，位置即最终位置。
  • 第17行：递归出口。第19~20行：左右两半继续分治——划分保证每轮至少把基准放好。

特点与考点

  • 不稳定：partition 的长距离交换会打乱相等元素的次序。
  • 最坏 O(n²)：每次划分都“一头全无”（如输入已有序且总取末元素为基准）。工程上用随机选基准 / 三数取中规避。
  • 常考：给数组画一趟 partition 的结果（见下方逐步执行）；比较 std::sort（内省排序：快排+堆排+插入的组合）与手写快排。

7. 归并排序（Merge Sort）

思想（分治）：① 从中间切一半；② 左右两半各自递归排好；③ 合并 merge：两个有序段像拉链一样，每次比较两头、取小的进结果——合并两个长度和为 n 的有序段只要 O(n)。无论输入如何都是 O(n log n)，且稳定；代价是合并需要 O(n) 的临时数组（不是原地排序）。

示例6：归并排序（重点看 merge）

知识点：归并 / 递归高频考点
#include <iostream>

// 合并两个已排序区间 a[lo..mid] 与 a[mid+1..hi]
void merge(int a[], int lo, int mid, int hi) {
    int temp[8];                       // 临时数组（示意，容量需 ≥ hi-lo+1）
    int i = lo, j = mid + 1, k = lo;   // 两个读指针，一个写指针
    while (i <= mid && j <= hi) {
        if (a[i] <= a[j]) temp[k++] = a[i++];   // 取小的；用 <= 保证稳定
        else              temp[k++] = a[j++];
    }
    while (i <= mid) temp[k++] = a[i++];    // 左段剩余直接搬
    while (j <= hi)  temp[k++] = a[j++];    // 右段剩余直接搬
    for (int t = lo; t <= hi; ++t) a[t] = temp[t];
}

void mergeSort(int a[], int lo, int hi) {
    if (lo >= hi) return;              // 单个元素天然有序
    int mid = lo + (hi - lo) / 2;      // 从中间切开
    mergeSort(a, lo, mid);             // 左半排好
    mergeSort(a, mid + 1, hi);         // 右半排好
    merge(a, lo, mid, hi);             // 合并两个有序段
}

int main() {
    int a[6] = {5, 2, 6, 1, 4, 3};
    mergeSort(a, 0, 5);
    for (int i = 0; i < 6; ++i) std::cout << a[i] << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
1 2 3 4 5 6

逐行解释

  • 第7~8行：两个读指针 i、j 指向两段的开头，谁小取谁、指针后移。相等时取左段（<=）——这就是归并稳定的全部秘密。
  • 第10~11行：一段取完后，另一段的剩余部分本来就有序，直接搬进 temp。
  • 第17行：lo + (hi - lo) / 2 而不是 (lo + hi) / 2——两者数学上等价，前者不依赖下标相加，是防溢出的工程习惯。
  • 第16行：递归出口：一个元素不用排。

特点与考点

  • 递归图景：像二叉树自底向上——先两两合并成长度 2 的有序段，再三三/六六合并。本例：{5,2,6}→{2,5,6}，{1,4,3}→{1,3,4}，最后一次 merge 合成整体。
  • 唯一稳定的高效排序（本表范围内），且最坏也是 O(n log n)——代价是 O(n) 额外空间。
  • 常考：手算 merge 一次的比较过程；问“为什么归并稳定而快排不稳定”。

8. 堆排序（Heap Sort，选讲）

思想：把数组看成完全二叉树（下标 i 的孩子是 2i+1 和 2i+2），先把它整理成大顶堆（每个父节点 ≥ 孩子），此时 a[0] 就是最大值；然后反复“堆顶换到末尾 → 剩余部分重新成堆”，最大、次大……依次沉到尾部。建堆 O(n)、每次调整 O(log n)，最好/平均/最坏都是 O(n log n)，且原地 O(1)——最坏情况比快排有保证；代价是不稳定、缓存不友好。

示例7：堆排序

知识点：堆 / 选择选讲
#include <iostream>

void siftDown(int a[], int n, int i) {       // 把 a[i] 沉到合适位置
    while (true) {
        int largest = i;
        int l = 2 * i + 1, r = 2 * i + 2;    // 左右孩子的下标
        if (l < n && a[l] > a[largest]) largest = l;
        if (r < n && a[r] > a[largest]) largest = r;
        if (largest == i) break;             // 已不比孩子小，停
        int t = a[i]; a[i] = a[largest]; a[largest] = t;
        i = largest;                          // 换下来的孩子还要继续查
    }
}

void heapSort(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; --i)      // ① 自底向上建大顶堆
        siftDown(a, n, i);
    for (int end = n - 1; end > 0; --end) {   // ② 逐个取走堆顶
        int t = a[0]; a[0] = a[end]; a[end] = t;
        siftDown(a, end, 0);                  // 剩余 end 个重新成堆
    }
}

int main() {
    int a[5] = {4, 10, 3, 5, 1};
    heapSort(a, 5);
    for (int i = 0; i < 5; ++i) std::cout << a[i] << " ";
    std::cout << "\n";
    return 0;
}
▶ 预期输出
1 3 4 5 10

要点

  • 本质是“选择排序的树化加速”：同样是每轮选最大放后面，但用堆把“找最大”从 O(n) 降到 O(log n)。
  • heapSort 第二个循环执行到 end=1 为止——最后一个元素自然就位。
  • 考试重点记三条：下标关系（父 i ↔ 孩子 2i+1、2i+2）、建堆从 n/2-1 开始、复杂度三档都是 O(n log n)。

9. 七种排序对比总表

算法最好平均最坏空间稳定性一句话要点
冒泡O(n)O(n²)O(n²)O(1)稳定相邻交换，大数沉底；每轮末尾多一个就位
选择O(n²)O(n²)O(n²)O(1)不稳定每轮选最小放前面；交换次数最少
插入O(n)O(n²)O(n²)O(1)稳定扑克摸牌；基本有序时飞快
希尔≈O(n)≈O(n^1.3)O(n²)O(1)不稳定分组插入，gap 逐轮减半
快排O(n log n)O(n log n)O(n²)O(log n)不稳定分治 + partition；实践中最快
归并O(n log n)O(n log n)O(n log n)O(n)稳定分治 + 合并有序段；稳定但费空间
堆排O(n log n)O(n log n)O(n log n)O(1)不稳定建堆 + 逐个取顶；最坏有保证
怎么记稳定性：“插冒归稳定，选希堆快不稳”。两个高频追问：① 快排最坏什么时候出现？已有序/逆序 + 固定取端点基准；② 归并为什么不常用于内部排序？O(n) 临时空间 + 搬运次数多。
工程视角：C++ 标准库的 std::sort 是内省排序——快排为主、递归过深转堆排（保住最坏情形）、小区间转插入排序（吃基本有序的便宜），三者取长补短。能用标准库就用标准库；手写这七种是为了考试与理解原理。

10. 常考题型与易错点

题型 1：手算第 k 轮后的数组。按算法规则逐轮推演即可，切忌“直接写排序结果”。口诀：冒泡尾部逐轮就位、选择头部逐轮就位、插入前缀逐轮有序、快排基准每趟就位。
题型 2：判断稳定性。给相等元素编号（3a、3b）手动跟踪。记住不稳定的长距离交换：选择的“最小换到开头”、快排的 partition、堆排的“堆顶换末尾”。
题型 3：快排一趟划分结果。用逐步执行跟着 i、j 走一遍最稳妥；答案必须让基准就位且左小右大。
易错 1：边界差一。冒泡内层 j < n - 1 - i：去掉 -i 不算错但白比；去掉 -1 则 a[j+1] 越界——未定义行为。
易错 2：比较器写坏是 UB。给 std::sort 传 a <= b 这类“不满足严格弱序”的比较器，相等元素上行为未定义，可能越界崩溃（原理见速查表·常用算法）。手写排序用 < / > 严格比较天然安全。
易错 3：归并的 temp 数组不够大是隐性越界；示例 6 里 temp[8] 只因演示数据只有 6 个元素，真实代码应开 hi - lo + 1 或用 vector 动态分配。
