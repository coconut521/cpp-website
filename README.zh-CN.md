# 大学 C++ 离线助教

**语言 / Language**：[简体中文](README.zh-CN.md) | [English](README.md) ｜ 开发说明 / Dev Guide: [DEV.md](DEV.md)

纯离线的 C++ 教学静态网站：HTML5 + CSS3 + 原生 JavaScript，**无 CDN、无网络请求、无构建步骤**。整个文件夹拷到任何电脑，双击 `index.html` 即可使用（`file://` 直接打开）。

> ⚠️ 页面中的示例输出为预置结果；真实编译请在本地使用 g++ / MSVC + VS Code 等工具。

---

## 一、快速上手

1. 把整个项目文件夹（含 `chapters/`、`assets/` 等子目录）拷贝到任意位置。
2. 双击 `index.html`，用浏览器（Chrome / Edge / Firefox 均可）打开。
3. 完成——不需要安装任何东西，也不需要联网。

也可以通过本地服务器访问（效果相同）：在项目根目录执行 `python -m http.server` 或 `npx serve`，然后浏览给出的地址。

## 三、功能说明

### 章节讲义
- **示例代码卡片**：每段示例可一键复制、下载为 `.cpp`、查看预置输出，进入**逐步执行**模式（当前行高亮 + 变量表 + 控制台），或点**▶ 在线运行**——内置的 WebAssembly 教学子集解释器会在页面里真实执行简单示例（`file://` 双击打开也能用；未定义行为会就地停止并说明，而不是给出编造的输出）。
- **互动元件**：内存可视化、**指针指向图**（SVG 分步演示赋地址 / 重新赋值 / 置空 / 悬空）、`i++` / `++i` 动画、拖拽排序、**Parsons 问题**（把打乱的代码行拖回正确程序）、左右代码对比、折叠答案。
- **逐步执行增强**：▶ 自动播放 + 速度档、递归示例的**调用栈侧栏**（看栈帧逐层压入弹出）、排序代码的**柱状图**动画（比较下标橙色、基准红色）。
- **测验**：选择、判断、填空、代码填空、**多空代码填空**（每个空分别判分、绿红标对错）五种题型，即时判分与解析；自测清单可逐条标记「会 / 不会」。
- **火眼金睛（找错练习）**：每章末尾自动插入一节「🔥 火眼金睛：本章找错」——通读一段藏有问题的代码，点击出问题的那一行提交判断，立即判分并给出解析（覆盖编译错误 / 逻辑错误 / 未定义行为三类）。
- **术语悬停解释**：正文中的术语（指针、多态、迭代器失效……49 个）自动带虚线下划线，鼠标悬停即出通俗解释，点击跳到对应章节；每章每词只标首次出现，不打扰阅读。
- **悬浮页内目录**：窗口较宽时左缘出现竖排「目录」按钮，点开可跳转到本章任意小节，滚动时自动高亮当前位置；窄窗口、投屏和打印时自动隐藏。
- **不会清单**：在各章「学习目标」「自测清单」里点「不会」，导航栏「🎯 不会清单」即汇总所有章节的薄弱知识点，可点击跳回对应章节。
- 页面底部自动生成"上一章 / 下一章"导航。

### 速查表（cheatsheets.html）
- 顶部搜索框可按表名或条目关键词过滤；分类按钮按领域筛选。
- 搜索框下方的**「直达」按钮**（优先级、string、vector、迭代器失效……）点击后跳到对应表格并高亮。
- 每张表右上角有复制按钮；`Ctrl+P` 可打印成 PDF（自动隐藏筛选栏）。

### 编译错误博物馆（errors.html）
- 支持按报错原文 / 关键词搜索，按分类和编译器（g++ / MSVC / VS 2026）筛选，一键展开或折叠全部。
- 「IDE 与工具链」分类收录 Visual Studio 2026 的高频问题：C4996 安全检查、窗口一闪而过、LNK1168 / LNK2005、中文乱码、默认 C++14 标准、Debug 缺 DLL、PDB 提示、IntelliSense 红线误报等。

### 排序算法专题（sorting.html）
- 7 种常考排序：冒泡/选择/插入各配逐步执行（行高亮 + 变量表），快排 partition 与归并 merge 可单步跟踪；希尔、堆排选讲思路。
- 复杂度/稳定性对比总表、常考题型（手算轮次、稳定性、一趟划分）、7+2 题随堂测验。

### 易错点（exam-pitfalls.html）
- 20 个专题，每个含错误写法、原因、正确写法与考试问答；顶部"随机练习 10 题"从题库随机出题。
- 「🔥 火眼金睛」找错训练：21 段藏 Bug 的代码（12 章各 1~2 题），点击可疑行提交判断，可按章节筛选、打乱顺序练习。

### 学习进度（首页）
- 每张章节卡片右下角有「已学完」勾选；目录上方进度条实时显示"已完成 x / 12 章"。
- 进度保存在浏览器 `localStorage` 中，**仅保存在当前电脑的当前浏览器里**——换电脑 / 换浏览器 / 清除浏览器数据都会丢失。点「重置进度」可清零。

### 全局搜索（首页）
同时覆盖章节、报错条目、速查条目、易错点、找错题与术语表，输入即出结果，点击直接跳转。

### 教师模式
开关方式（任选其一）：右上角「🧑‍🏫 教师」按钮 / 地址栏加 `?teacher=1` / 快捷键 `Ctrl+Alt+T`。
开启后可：显示全部答案与输出、展开所有折叠块、批量导出本章示例为 `.cpp`、一键生成新章节模板，以及**📑 随机组卷**——按题数 / 难度 / 题型 / 章节范围从跨章题库（题库 + 易错点小题 + 找错题）随机抽题组卷，试卷与答案页分开显示，`Ctrl+P` 即可直接打印练习卷（自动只打印试卷本身）。

### 投屏演示模式
点击右上角「🖥 投屏」按钮（或快捷键 `Ctrl+Alt+P`）进入：页面按小节自动分成一屏一屏，`←` `→` / 空格翻页，`Esc` 退出；进入时自动尝试全屏并整体放大字号，适合课堂投影逐屏讲解。也可以在地址栏加 `?present=1` 直接进入。

### 外观与打印
- 右上角 `A－` / `A＋` 调整字号；主题按钮在 **☀️ 亮色 → 🌙 暗色 → 💻 跟随系统** 三态间循环切换，「跟随系统」会随操作系统的深浅色设置实时变化（均自动记忆）。
- 打印任一页面（`Ctrl+P`）会自动隐藏交互按钮、展开全部输出与折叠块，适合导出 PDF 讲义。

## 四、注意事项

- 页面中预置的示例输出仍是教学基准；新增的「▶ 在线运行」按钮使用**教学子集解释器**（WebAssembly）：支持前几章常用语法（变量、运算、分支循环、函数递归、引用参数、一维数组、cout），未覆盖的语法会明确提示，涉及未定义行为（未初始化读取、有符号溢出、除零、数组越界、递归过深）时会**就地停止并解释原因**，绝不给出编造输出。UB 一律红色标注的原则不变，且**不会**作为"预测输出"类考题。
- 全站无任何网络请求，可放心在无网机房 / 考试环境使用。WASM 解释器随文件夹一起分发：`http(s)` 下浏览器加载独立的 `.wasm` 文件，`file://` 下自动改用内嵌 base64 版。
- 想参与建设内容（加章节、加速查表、改样式）？请看 [DEV.md](DEV.md)。
